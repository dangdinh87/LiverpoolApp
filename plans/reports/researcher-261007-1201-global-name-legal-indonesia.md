## 2. Legal / trademark
- LFC registers crest and other IP worldwide and runs a Brand Protection team against social profiles, blogs and sites using LFC trademarks/content.
- UDRP/WIPO practice for fan sites: legitimate only if active, non-commercial, clearly distinct from the official site, not reproducing the mark. Fan sites with PPC/automated ads are normally NOT treated as non-commercial.
- Implication: the current domain `liverpoolfcvn.blog` (club name in domain) + AdSense is the weakest combination. New domain should not contain "liverpool"/"lfc"/crest; keep disclaimer; keep crests only as match data. "Kop"/"Reds" generic-ish but unverified at registry level.
- Vietnam: NĐ 147/2024 distinguishes organisation "tổng hợp" sites from personal sites (see earlier report) — unchanged.

## 3. Indonesia (pilot candidate)
- Premier League rights: Emtek/Vidio exclusive through 2027-28 (+ NEX Parabola satellite). Where-to-watch for ID = Vidio.
- "jadwal Liverpool" queries are already served by Goal.com ID, Flashscore.co.id, FotMob, Traveloka Explore, Sky Sports.
- Calendar-subscription (ICS) tools in local time already exist (fixtur.es, matchesio, premierleagueschedule.org, matchcalendar.football, kickoff.guide).
=> Schedule/time utility is table stakes, not a moat. Moat must be Liverpool-only depth + a voice + community.

## 4. Revised recommendation
1. Keep utility (local-time fixtures, where-to-watch table, ICS feed) as the free hook, but lead with original EN commentary (pre/post-match notes, daily digest with human review).
2. Indonesian pilot only after EN shows Search Console traction; if done, translate original commentary with a native reviewer, not just utility pages.
3. Name: **Reds Abroad** (no collisions, describes the audience) first choice; **KopClock** if utility-first. Check TM + handles + .com purchase.
4. Migrate off `liverpoolfcvn.blog` with 301s once the new domain is live.
