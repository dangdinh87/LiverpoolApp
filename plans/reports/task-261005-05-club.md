## Goals
1. **History**: storytelling page — compact hero, sticky scrollable in-page nav (Timeline / Trophies / Legends / Stadium), timeline as a vertical rail on mobile (alternating on desktop), trophy cabinet as a tile grid with counts, legends cards, stadium section with a CSS scroll-snap gallery. Photos via `next/image` with `sizes`, lazy below the fold; backgrounds ≤200KB.
2. **Gallery**: grid that never shifts layout (stored width/height or aspect boxes), category chips (hide counts when unknown instead of showing 0), lightbox with keyboard (←/→/Esc), touch swipe, focus trap + focus return, preload neighbours only, "load more" with skeletons; admin controls hidden unless admin. Grid thumbnails use the existing `thumbSrc()` helper in gallery-content.tsx (smaller renditions); full size only in the lightbox.
3. **About / Legal**: readable long-form (65ch, clear headings, anchors for Privacy / Terms / Data sources with a small table of contents), contact block, bilingual.
4. **Profile**: settings-style page — avatar upload with preview/progress/errors, username/bio form with inline validation, favourite players grid, saved articles list, sign-out; logged-out = clear sign-in prompt (no redirect flash). Skeleton matching. (Logged-in can't be screenshotted without credentials — verify by code reading and say so.)
5. **Chat page** (/chat): full-height app-like layout, conversation list as a drawer on mobile, composer pinned above the keyboard (safe-area, `100dvh`), smooth message scrolling, a visible but unobtrusive "Home" exit (a back link exists in chat/layout.tsx — keep), empty state with 3–4 suggested prompts (bilingual: next match, standings, latest news, squad) that fill the composer.
6. `loading.tsx` for history, gallery, about, profile matching layouts.
